# Conditions

## If Else if Else

<SandBox precode='
{
    int a = 2, b = 3;
    if (a > b && true) {
        println("A (", a,") est plus grand que B (", b,")");
    } else {
        println("A (", a,") est plus petit ou égale à B (", b,")");
    }
}

---

Les conditions permettent d'exécuter du code en fonction de valeur de variables.

```txt title="Syntaxe"
if (expr) {
    code si vrai
} else if (expr) {
    code si seconde condition vrai
}
else {
    code si faux
}
```
